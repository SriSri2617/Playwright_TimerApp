User Stories

    Created user stories and test scenarios for the Timer App application and automated them using Playwright end-to-end tests.


Examples include:

    - Creating and deleting timer and note widgets.    
    - Swapping two widgets.    
    - Changing time settings on a timer.    
    - Starting, pausing, and resetting the timer.    
    - Editing note text with negative validation (rejecting empty inputs).    
    - Changing theme colors dynamically.


End-to-End Testing with Playwright

    Implemented automated UI tests using:    
       - Python    
       - Pytest    
       - Playwright


The tests verify:

    - Page loading and element visibility.    
    - Widget creation, deletion, and swapping.    
    - Negative input validation for notes.    
    - Timer control states (start, tick verification, pause, reset).    
    - Theme switching and data-theme attribute verification on the <html> element.


Tools Used
