User Story 1 : Create and Delete Timer Widgets
    As a user, I want to create and delete timer widgets so that I can manage the timers I need on my dashboard.

Acceptance Criteria:
   1.1. Given the dashboard is open, when the user clicks "Add Timer", then a new timer widget is displayed.
   1.2. Given a timer widget exists, when the user clicks its delete button, then the timer widget is removed.
    
Test Scenarios:
1.1. Create a Time Widget
    1. Open the application.
    2. Click the "Add Timer" button.
    3. Verify that a new timer widget appears.

Expected Result: A new timer widget is displayed.
    
1.2. Delete a timer widget
    1. Create a timer widget.
    2. Click the delete button on the timer.
    3. Verify that the timer widget disappears.

Expected Result: The timer widget is removed from the dashboard.

User Story 3: Swap Two Widgets
    As a user, I want to rearrange widgets so that I can organise my dashboard as I prefer.

Acceptance Criteria:
    3.1. Given at least two widgets exist, when the user drags one widget to another position, then the widget order is updated.
    3.2. Given widgets contain data, when widgets are moved, then their content remains unchanged.

Test Scenarios
3.1: Swap positions of two widgets
    1. Click on timer widget.
    2. Click a note widget.
    3. Note their original positions.
    4. click on Up Arrow icon in the note widget.
    5. Verify the order has changed.

Expected Result: The widgets appear in the new order.

3.2: Verify content remains after swapping
    1. Add text to a note widget.
    2. Reorder the widgets.
    3. Verify the note still contains the entered text.

Expected Result: Widget data remains unchanged.

User Story 4: Start, Pause, and Reset a Timer
    As a user, I want to start, pause, and reset a timer so that I can control the countdown.

Acceptance Criteria:
    4.1 Given a timer exists, when the user clicks Start, then the timer begins counting down.
    4.2 Given a timer is running, when the user clicks Pause, then the countdown stops.
    4.3 Given a timer has been started or paused, when the user clicks Reset, then the timer returns to its original value.

Test Scenarios
4.1: Start a timer
    1. Click on Add Timer
    2. Click Start.
    3. Wait a few seconds.
    4. Observe the timer value.

Expected Result: The timer value decreases over time.

4.2: Pause a timer
    1. Click on Add timer.
    2. Start the timer.
    3. Wait a few seconds.
    4. Click Pause.
    5. Observe the time value for several seconds.

Expected Result: The timer value does not change while paused.

4.3: Reset a timer
   1. Start the timer.
   2. Wait a few seconds.
   3. Click Reset.

Expected Result: The timer returns to its original configured value.
